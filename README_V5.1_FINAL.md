## 🔧 إعداد الذكاء الاصطناعي

### الخيار 1: استخدام بدون AI (جاهز فوراً)
```
✅ التطبيق يعمل بكامل ميزاته الأساسية
✅ لا تحتاج لإعداد أي شيء
✅ يعمل بدون إنترنت بالكامل
```

### الخيار 2: تفعيل AI (للميزات المتقدمة)

#### 1. احصل على OpenAI API Key

```bash
# 1. اذهب إلى
https://platform.openai.com/api-keys

# 2. سجل دخول / أنشئ حساب

# 3. اضغط "Create new secret key"

# 4. سمّه: "Document Archive"

# 5. احفظ المفتاح (يبدأ بـ sk-proj-...)
```

#### 2. فعّل في التطبيق

```dart
// 1. افتح: lib/config/api_config.dart

// 2. استبدل المفتاح:
static const String openAIKey = 'sk-proj-YOUR_KEY_HERE';

// 3. أعد بناء التطبيق
```

#### 3. استخدم الميزات

```
🔧 افتح التطبيق
⚙️ القائمة → إعدادات AI
✅ تحقق من الحالة
🧪 اختبر الخدمات
```

## 🛠️ التطوير والمساهمة

### البناء من المصدر

```bash
# 1. استنساخ المشروع
git clone https://github.com/Walsat/Walsat.git
cd Walsat

# 2. تبديل إلى فرع التطوير
git checkout genspark_ai_developer

# 3. إعداد API keys (اختياري)
cp lib/config/api_config.example.dart lib/config/api_config.dart
# عدّل api_config.dart بمفاتيحك

# 4. تثبيت الحزم
flutter pub get

# 5. بناء Hive files
dart run build_runner build --delete-conflicting-outputs

# 6. بناء APK
flutter build apk --release

# 7. APK موجود في:
# build/app/outputs/flutter-apk/app-release.apk
```

### الفروع
```
🌿 main - النسخة المستقرة
🌿 genspark_ai_developer - التطوير النشط
```
