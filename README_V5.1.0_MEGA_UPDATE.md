## 📖 كيفية الاستخدام

### تسجيل الدخول
1. افتح التطبيق
2. اختر "تسجيل الدخول بحساب Google" أو "المتابعة كضيف"
3. إذا اخترت Google، سيُطلب منك تسجيل الدخول
4. سيتم حفظ بياناتك محلياً للجلسات القادمة

### التصنيف التلقائي
1. اذهب إلى "إضافة وثيقة"
2. التقط صورة للوثيقة أو اختر من المعرض
3. انقر على زر "التصنيف التلقائي بالذكاء الاصطناعي"
4. انتظر التحليل (5-10 ثواني)
5. سيتم ملء جميع الحقول تلقائياً!

### الطباعة المباشرة
1. افتح تفاصيل وثيقة
2. انقر على زر "طباعة"
3. اختر إحدى الخيارات:
   - "طباعة مباشرة" - للطباعة الفورية
   - "معاينة" - لمعاينة PDF أولاً
   - "مشاركة PDF" - للمشاركة عبر التطبيقات

### إدارة مفاتيح API
1. اذهب إلى "الإعدادات"
2. انقر على "إدارة مفاتيح API"
3. أدخل مفتاح OpenAI و/أو Google Vision
4. انقر "اختبار" للتحقق من الاتصال
5. احفظ المفاتيح

- إمكانية تسجيل الخروج في أي وقت

- لا يتم مشاركة مفاتيحك مع أي طرف ثالث
- الحفظ المحلي فقط
