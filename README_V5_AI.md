## 📖 دليل الاستخدام

### 1. إضافة وثيقة جديدة:

1. اضغط زر "إضافة وثيقة" ➕
2. أدخل العنوان
3. اختر التصنيف:
   - كتب دائرة الأراضي
   - وزارة الزراعة
   - محافظ صلاح الدين
   - مديرية الزراعة
   - شعبة الزراعة
   - أوامر مهمة
   - الأبيض الشكوي
4. اختر الحالة: جديد / تحت المراجعة / مكتمل / مؤرشف
5. أضف التفاصيل والصور
6. اضغط "تحليل الوثيقة" للتحليل بالـ AI (اختياري)
7. اضغط "استخراج النص" للـ OCR (اختياري)
8. احفظ ✓

### 2. تحليل وثيقة بالذكاء الاصطناعي:

1. أضف صورة الوثيقة
2. اضغط "تحليل الوثيقة" 🧠
3. انتظر التحليل (دقيقة واحدة)
4. اقرأ النتائج:
   - نوع الوثيقة
   - رقم الوثيقة
   - تاريخ الإصدار
   - الأسماء المذكورة
   - ملخص المحتوى
5. احفظ الوثيقة

### 3. استخراج النص (OCR):

1. اضغط "استخراج النص" 📝
2. انتظر قليلاً
3. النص سيظهر في حقل خاص
4. يمكن البحث في النص لاحقاً

### 4. البحث الذكي:

1. اضغط أيقونة البحث 🔍
2. اكتب ما تبحث عنه
3. استخدم البحث العادي أو البحث الذكي
4. البحث الذكي يفهم السياق والمعنى

### 5. الطباعة والمشاركة:

1. افتح الوثيقة
2. اضغط القائمة ⋮
3. اختر "إنشاء PDF" أو "طباعة"
4. أو "مشاركة" لإرسال PDF

### 6. النسخ الاحتياطي على Google Drive:

1. سجل دخول بحساب Google
2. فعّل النسخ الاحتياطي
3. اختر مجلد Drive
4. المزامنة التلقائية

## 💡 نصائح للاستخدام الأمثل

### للحصول على أفضل نتائج AI:

1. **صور واضحة:**
   - التقط صور بإضاءة جيدة
   - تأكد من وضوح النص
   - تجنب الانعكاسات

2. **زاوية صحيحة:**
   - صوّر من الأعلى مباشرة
   - تجنب الزوايا المائلة
   - الوثيقة كاملة في الإطار

3. **جودة عالية:**
   - استخدم أعلى جودة للكاميرا
   - لا تقص الصورة كثيراً
   - الدقة المطلوبة: 1920x1920 على الأقل

### لتوفير استهلاك API:

1. استخدم AI فقط عند الحاجة
2. استخرج النص مرة واحدة فقط
3. حلل الوثائق المهمة فقط
4. استخدم البحث العادي عندما يكفي
