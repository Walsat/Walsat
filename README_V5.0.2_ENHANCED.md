### 1. **شاشة الإعدادات الشاملة** 🎛️


#### **المحتويات:**

**أ. المظهر** 🎨
- تبديل الوضع الليلي/النهاري

**ب. الذكاء الاصطناعي** 🤖

**ج. إدارة البيانات** 💾
- **ضغط الصور تلقائياً**: توفير مساحة التخزين
- **نسخ احتياطي تلقائي**: حماية بياناتك
- **تصدير البيانات**: حفظ نسخة من جميع الوثائق
- **استيراد البيانات**: استعادة نسخة احتياطية
- **حذف البيانات**: مسح كامل للتطبيق

**د. المساعدة والدعم** 📖
- دليل الاستخدام السريع
- نصائح وإرشادات
- معلومات التطبيق
- سياسة الخصوصية
