## 📥 التحميل والتثبيت

### الطريقة 1: التحميل المباشر من GitHub
```
رابط التحميل:
https://github.com/Walsat/Walsat/raw/genspark_ai_developer/document-archive-v4.0.0.apk
```

### الطريقة 2: تثبيت من الهاتف مباشرة
1. افتح المتصفح في هاتفك
2. اذهب إلى: `github.com/Walsat/Walsat`
3. انتقل إلى فرع `genspark_ai_developer`
4. حمّل ملف `document-archive-v4.0.0.apk`
5. افتح الملف المحمّل
6. اسمح بالتثبيت من مصادر غير معروفة (إن طُلب منك)
7. اضغط "تثبيت"

### تفعيل التثبيت من مصادر غير معروفة:

#### Android 8.0+:
1. الإعدادات → التطبيقات → الوصول الخاص
2. تثبيت التطبيقات غير المعروفة
3. اختر المتصفح أو مدير الملفات
4. فعّل "السماح من هذا المصدر"

#### Android 7.0 وأقدم:
1. الإعدادات → الأمان
2. فعّل "مصادر غير معروفة"
