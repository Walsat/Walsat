# 🚀 أرشيف الوثائق v5.1.0 - النسخة المتقدمة
# Document Archive v5.1.0 - Advanced Edition

## 📋 نظرة عامة
الإصدار v5.1.0 يمثل قفزة نوعية في تطبيق أرشيف الوثائق، مع إضافة ميزات متقدمة تشمل:
- ✨ إدارة مفاتيح API الشخصية للذكاء الاصطناعي
- 🤖 التصنيف التلقائي الذكي للوثائق
- 🖨️ الطباعة المباشرة والمعاينة
- 🌐 تسجيل الدخول بحساب Google
- 🎨 واجهة Material Design 3 المحسّنة

---

## 🆕 الميزات الجديدة

### 1. 🔑 إدارة مفاتيح API الشخصية
**شاشة مخصصة لإدارة مفاتيح API**
- ✅ إضافة مفتاح OpenAI API الخاص بك
- ✅ إضافة مفتاح Google Vision API
- ✅ اختبار صحة المفاتيح فوريًا
- ✅ حفظ آمن ومشفر للمفاتيح
- ✅ إرشادات تفصيلية للحصول على المفاتيح
- ✅ روابط مباشرة لمواقع التسجيل

**المسار:** الإعدادات ← الذكاء الاصطناعي ← إدارة مفاتيح API

**المميزات الأمنية:**
- 🔒 تخزين محلي آمن
- 🔐 عدم إرسال المفاتيح للخوادم الخارجية
- 👁️ إخفاء المفاتيح عند العرض
- ✅ التحقق من صلاحية المفاتيح قبل الحفظ

### 2. 🤖 التصنيف التلقائي الذكي
**تحليل شامل وتلقائي للوثائق باستخدام GPT-4 Vision**

**ما يتم استخراجه تلقائيًا:**
- 📂 نوع الوثيقة (التصنيف الدقيق من 8 فئات)
- 📝 العنوان والموضوع الرئيسي
- 📅 التاريخ
- 🏢 الجهة المصدرة
- 👤 الأسماء المذكورة
- 📍 المواقع
- #️⃣ الأرقام المهمة
- 📄 ملخص المحتوى
- 🏷️ الكلمات المفتاحية (وسوم تلقائية)
- 📊 الحالة المقترحة

**كيفية الاستخدام:**
1. افتح شاشة إضافة وثيقة
2. التقط صورة الوثيقة أو اختر صورة موجودة
3. اضغط على "🤖 تحليل الوثيقة"
4. انتظر 10-30 ثانية للحصول على النتائج
5. يتم ملء جميع الحقول تلقائيًا!
6. راجع وعدّل إذا لزم الأمر
7. احفظ الوثيقة

**متطلبات الاستخدام:**
- مفتاح OpenAI API صالح
- اتصال بالإنترنت
- صورة واضحة للوثيقة

### 3. 🖨️ الطباعة المباشرة
**طباعة احترافية للوثائق مباشرة من التطبيق**

**المميزات:**
- ✅ طباعة فورية للوثيقة
- 👁️ معاينة الطباعة قبل الإرسال
- 📄 تنسيق PDF احترافي
- 🎨 تصميم جذاب مع ألوان مميزة
- 📋 يتضمن جميع معلومات الوثيقة
- 🖼️ يشمل صور الوثيقة
- 📊 دعم طباعة قوائم متعددة

**كيفية الاستخدام:**
**من شاشة تفاصيل الوثيقة:**
1. افتح أي وثيقة
2. اضغط على أيقونة الطباعة 🖨️ في الشريط العلوي
   أو اختر من القائمة ⋮:
   - "طباعة مباشرة" للطباعة الفورية
   - "معاينة الطباعة" لرؤية التصميم أولاً
3. اختر الطابعة
4. اضغط طباعة!

**التنسيق:**
- حجم A4 قياسي
- اتجاه النص من اليمين لليسار (RTL)
- خط Cairo العربي الجميل
- رأسية ملونة بتدرجات احترافية
- تذييل يحتوي على تاريخ ووقت الطباعة

### 4. 🌐 تسجيل الدخول بحساب Google
**نظام مصادقة آمن ومريح**

**المميزات:**
- ✅ تسجيل دخول سريع بنقرة واحدة
- 🔐 أمان عالي باستخدام Firebase
- 📱 مزامنة عبر الأجهزة (قريبًا)
- 💾 نسخ احتياطي سحابي (قريبًا)
- 🔄 إدارة حساب كاملة

**كيفية الاستخدام:**
1. افتح التطبيق لأول مرة
2. اضغط "تسجيل الدخول بحساب Google"
3. اختر حسابك
4. وافق على الأذونات
5. ابدأ الاستخدام!

**يمكنك أيضًا:**
- المتابعة كضيف بدون حساب
- تسجيل الخروج من الإعدادات
- إدارة حسابك من الإعدادات

### 5. 🎨 تحسينات واجهة المستخدم

**التحسينات:**

- 📱 تصميم متجاوب

## 🔧 دليل الاستخدام السريع

### الإعداد الأولي
1. **تنزيل التطبيق**
   - قم بتنزيل ملف APK
   - تأكد من MD5: `e10488f5c77937be3d1604fa052195e2`

2. **التثبيت**
   - اسمح بالتثبيت من مصادر غير معروفة
   - قم بتثبيت التطبيق
   - افتح التطبيق

3. **تكوين الذكاء الاصطناعي (اختياري)**
   - اذهب إلى: الإعدادات → الذكاء الاصطناعي → إدارة مفاتيح API
   - أضف مفتاح OpenAI API: https://platform.openai.com/api-keys
   - أو أضف مفتاح Google Vision API
   - اختبر المفاتيح
   - احفظ

4. **تسجيل الدخول (اختياري)**
   - اختر "تسجيل الدخول بحساب Google"
   - أو اختر "متابعة كضيف"

5. **ابدأ الاستخدام!**
   - أضف وثيقة جديدة
   - التقط صورة أو اختر من المعرض
   - استخدم التصنيف التلقائي إذا كان متاحًا
   - احفظ وابدأ الأرشفة!

### سير العمل الموصى به
```
1. 📸 التقاط صورة الوثيقة
   ↓
2. 🤖 تحليل تلقائي بالذكاء الاصطناعي
   ↓
3. ✏️ مراجعة وتعديل المعلومات
   ↓
4. 💾 حفظ الوثيقة
   ↓
5. 🖨️ طباعة إذا لزم الأمر
   ↓
6. 📊 تصفح وبحث في الأرشيف
```

## 🐛 المشاكل المعروفة والحلول

### التصنيف التلقائي لا يعمل
**الحل:**
1. تأكد من إضافة مفتاح OpenAI API
2. تحقق من صحة المفتاح (زر "اختبار")
3. تأكد من الاتصال بالإنترنت
4. جرّب مرة أخرى

### الطباعة لا تعمل
**الحل:**
1. تأكد من وجود طابعة متصلة
2. تحقق من أذونات التطبيق
3. جرّب معاينة الطباعة أولاً
4. حاول من خلال "إنشاء PDF" ثم الطباعة

### تسجيل الدخول فشل
**الحل:**
1. تحقق من الاتصال بالإنترنت
2. أعد المحاولة
3. استخدم "متابعة كضيف" كبديل
